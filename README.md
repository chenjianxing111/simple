# Vibe Todo / 待办清单

一个用 AI 辅助快速生成的前端单页小工具，用于记录和管理日常待办事项。

## 基本用途

- 添加任务：在输入框输入内容，按回车或点击“添加”。
- 标记完成：点击任务左侧的圆圈或任务文字，切换完成/未完成状态。
- 删除任务：点击右侧的“删除”。
- 数据保存在浏览器 localStorage 中，刷新页面不丢失。

## 设计思路

本项目通过“用自然语言描述需求 → AI 生成初版 → 人工审查与微调”的方式完成，目标是验证从想法到可运行成品的完整闭环，而非追求生产级代码质量。项目不依赖后端、数据库或构建工具，所有逻辑在浏览器端完成，直接打开 `index.html` 即可使用。

开发过程中主要关注三点：数据用数组管理并通过 localStorage 持久化；列表交互采用事件委托，避免为每个按钮单独绑定事件；代码保持最小可读，便于快速验证和修改。
